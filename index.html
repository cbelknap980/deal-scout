A site is marked connected only if a successful collector run for that site is recorded. Listings imported previously are shown separately.

How sources become active

Facebook Marketplace and Craigslist require configured, authorized alert ingestion. Other marketplaces can use documented APIs, permitted public feeds, or manual imports. GitHub Actions is scheduled, but no source feed is currently configured. Listing notifications and credentials must never be committed to this public site.

Saved searches

All original search fields are restored. GitHub Pages has no private database: saved edits on this page stay in this browser only. Export settings to carry them elsewhere.

Sites to include

ZIP/radius, sources and email alert preferences are recorded for the future collector integration; they do not yet activate remote scraping or send email.

Import external listings

Paste JSON or JSONL records. Each record needs a title, HTTPS link, source, searchId, and optionally numeric price. These records are stored only in your current browser until uploaded to the repository.
